## Logistic Regression Minor Project

## Overview
This project demonstrates the implementation of Logistic Regression
to solve a classification problem using Python.

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

## Project Steps
1. Data preprocessing
2. Exploratory Data Analysis
3. Model training using Logistic Regression
4. Model evaluation

## Results
The model predicts the target variable with good accuracy and
demonstrates how logistic regression can be applied to classification problems.
